# CapMesh Demo

Walk through each step to understand how CapMesh works.

## Run in order

```bash
python demo/01_create_tool.py       # How to write a Tool manifest
python demo/02_create_agent.py      # How to write an Agent manifest
python demo/03_create_skill.py      # How to write a Skill manifest
python demo/04_register_and_build.py # How to register and build
python demo/05_use_in_code.py       # How to use in your application
python demo/06_benefits.py          # See all 7 benefits proven live
```

## Or run all at once

```bash
for f in demo/0*.py; do python "$f"; echo; done
```
